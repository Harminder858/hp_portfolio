## 🏗️ Architecture

**This repo (PUBLIC):**
- ✅ Website files (HTML/CSS/JS)
- ✅ Published articles
- ✅ Article images & visualizations
- ❌ NO automation code
- ❌ NO API keys

**Private automation repo:**
- 🔒 Article generation code
- 🔒 AI integration (Claude API)
- 🔒 n8n workflows
- 🔒 Sync scripts

See [SPLIT_REPO_SETUP.md](SPLIT_REPO_SETUP.md) for details on the split architecture.

## 🚀 How It Works

1. **Private repo** generates articles with AI
2. **Sync script** copies articles to this public repo
3. **GitHub Pages** publishes automatically
4. **Website** updates with new content!
